# ATS WestPlay：第一次下载、安装与使用

本指南适用于从 [enes-less/WestPlay](https://github.com/enes-less/WestPlay) 2.1.2 修改移植的 ATS 分支。请下载本仓库的 ATS 安装包；上游 ETS2 安装包用于另一个游戏。本分支继续使用 GPL-3.0-or-later，原作者和第三方声明均予以保留。

## 1. 使用前准备

需要 Windows 10 / 11 64 位、Microsoft Edge WebView2 Runtime、可正常运行的 Steam 版《美国卡车模拟》，以及合法拥有并启用的官方 **Road Trip: Ford DLC**。目标车辆为 DLC 中的 **2023 Ford F-150**。

当前实际验证版本为 **ATS 1.61.3.18s，DirectX 11，Windows x64**。先确认原游戏能正常进入自己的存档。通过 Steam 启动时选择 **DirectX 11**，使用中控期间也保持这个渲染模式。

如果安装器提示 WebView2 缺失或损坏，请按提示前往 [微软官方 WebView2 下载页面](https://developer.microsoft.com/microsoft-edge/webview2/) 安装 Runtime，然后重新运行安装器。

## 2. 下载什么文件

打开本仓库的 [最新发布页面](https://github.com/wadelyyy/WestPlay-ATS/releases/latest)，展开 **Assets**：

| 文件 | 用途 |
| --- | --- |
| 名字以 `_x64-setup.exe` 结尾的程序，例如 `ATS-WestPlay_2.1.2_x64-setup.exe` | 普通用户下载安装的入口 |
| 本分支源码 ZIP | 完整源码，供阅读、修改及自行构建 |
| GitHub 自动生成的 `Source code (zip)` / `Source code (tar.gz)` | 同样是源码归档，不能直接安装或双击运行 |
| SHA256 校验文件 | 用于核对下载文件是否完整 |

安装包不附带游戏本体、Ford DLC、存档或游戏地图归档。首次设置会从本机游戏生成所需地图和中控资源。

## 3. 安装和首次设置

1. 通过游戏菜单 **正常退出 ATS**。部署或更新插件时，游戏应处于关闭状态。
2. 运行下载的安装程序，可以选择简体中文。按需要选择安装目录、桌面和开始菜单快捷方式。
3. 打开 **ATS WestPlay**，按首次设置向导确认 ATS 安装目录。通常可自动识别 Steam 位置；未识别时在向导中选择游戏文件夹。
4. 按向导安装游戏插件和中控屏资源。复制文件需要 Windows 权限时，按提示授权。若提示游戏仍在运行，先自行正常退出游戏后重试。
5. 等待地图数据准备完成。所需时间取决于本机游戏内容、DLC、磁盘和缓存情况；首次准备期间不要把「等待游戏」当作安装失败。
6. 完成操作教程，进入 **ATS 启动台**。此时可以看到 WestPlay 服务、游戏遥测和车内中控屏的状态。

上述配置通常只需完成一次。重新安装或升级后，如提示插件不匹配，在游戏关闭时使用「诊断与修复」。

## 4. 启动游戏并显示中控

1. 保持 WestPlay 运行，打开 Steam，**手动启动 ATS，选择 DirectX 11**。如游戏弹出 SDK 插件提示，阅读后确认。
2. 进入自己的存档，使用官方 **2023 Ford F-150**。
3. 切换到驾驶室第一人称视角，并按游戏中自己的键位 **打开车辆电源**。发动机按键以游戏设置为准。
4. 把原车中控切到 **GPS / 导航页面**，等待 WestPlay 画面出现。
5. 需要确认连接时，切回电脑上的 ATS 启动台，查看服务和游戏遥测是否已连接，以及中控屏是否正在绘制。

**点击桌面或开始菜单的「ATS WestPlay」只打开伴侣程序，不会自动启动美卡。** 你也可以先开 ATS、再开 WestPlay；两者都运行后会自动连接。游戏未启动时显示「等待游戏」属于正常状态。

如果确实希望由 WestPlay 启动游戏，可以主动点击启动台的「启动 ATS 游戏」按钮。仅打开 WestPlay 不会触发它。

## 5. 怎样用鼠标操作车屏

先让游戏窗口获得焦点，回到驾驶画面。交互键和模式可以在 WestPlay 电脑端的 **「控制」** 页修改，以当前页面显示为准。

默认交互键是 **左 Alt**，有两种模式：

| 控制模式 | 进入中控操作 | 退出中控操作 |
| --- | --- | --- |
| 长按 | 按住左 Alt，并用鼠标操作屏幕 | 松开左 Alt |
| 开启「按一次，无需按住」 | 按一下左 Alt 后松开 | 再按一下左 Alt |

进入中控操作后，用鼠标左键点击按钮，使用滚轮缩放地图。退出操作后继续正常控制驾驶视角。游戏暂停或进入菜单后，返回驾驶画面时可能需要再次进入操作模式。

默认媒体快捷键使用 **主键盘数字键**：

| 按键 | 功能 |
| --- | --- |
| `1` | 降低 WestPlay 媒体音量 |
| `2` | 播放 / 暂停 |
| `3` | 提高 WestPlay 媒体音量 |

长按模式下，操作这些键时同时按住左 Alt；按一次模式下，先进入中控操作模式。若绑定与自己的游戏按键冲突，可在 WestPlay「控制」页改键。建议停车后搜索地点、登录媒体或操作视频。

## 6. 地图、导航和原厂画面

进入中控操作，打开 **Maps**。可以搜索地点，也可以选择附近的加油站、停车场等设施，选择目标后点击 **Go / 前往**；出现路线预览时，再点击一次确认。路线可交给游戏导航，地图随车辆位置更新。

点击车屏侧栏的车辆图标可以回到 Ford 原厂画面。重新显示 WestPlay 时，使用原车画面上的 WestPlay 标志，或电脑端「卡车屏幕」页的「显示 WestPlay」开关。隐藏界面并不等于退出伴侣程序。

已实际验证附近设施搜索、游戏导航同步和公共道路短途 GPS 跟随；不代表所有路线、DLC 或地图 MOD 都已验证。

## 7. YouTube 和其他媒体

### 无需登录的 YouTube

停车后进入中控操作，从应用列表打开 **YouTube**，选择或搜索可公开播放的视频并点击播放。可用页面按钮或默认数字键 `2` 播放 / 暂停，数字键 `1` / `3` 调整 WestPlay 音量。

已在真实 ATS 中验证未登录公开视频播放、暂停、返回和非零音频输出。具体视频是否可用仍由网络、服务和内容自身的地区 / 年龄限制决定。

### Apple Music、Spotify、YouTube Music

在电脑端的「账号」或「音乐与视频账户」入口选择服务，按它的 **官方登录页面** 完成授权。部分功能需要账号或订阅。账号密码只在服务自己的授权页面输入，不要提交到 GitHub Issue 或聊天中。

Apple Music 未登录首页已实际打开；Spotify、Apple Music 订阅播放、YouTube Music、歌词和完整账户流程尚未完成端到端验证，不能用 YouTube 的测试结果代替。

## 8. 日常关闭、更新和修复

使用中控时保持 ATS 和 WestPlay 同时运行。通过 ATS 游戏菜单正常退出游戏；不需要伴侣程序时，再关闭 WestPlay。下次分别打开两个程序即可，不必重复首次安装。

本分支关闭了原 ETS2 自动更新入口。更新时从 **本仓库 Releases** 下载 ATS 安装包，正常退出游戏和 WestPlay 后运行新版安装程序。安装完成后按提示检查插件；需要更新游戏端文件时，在游戏关闭状态下点击「诊断与修复」。

需要卸载时，先正常退出 ATS，在 WestPlay 的 **「安全卸载」** 入口移除游戏端组件，并按页面选项决定是否保留设置和地图；之后可在 Windows「已安装的应用」中卸载伴侣程序。请按实际页面的删除范围作选择。

## 9. 常见问题

| 现象 | 检查方法 |
| --- | --- |
| 只显示「等待游戏」 | 手动启动 ATS；仅打开 WestPlay 不会自动开游戏 |
| 遥测连接不上 | 启动台点「检查连接」，核对游戏目录和插件状态；需修复时先退出游戏 |
| 遥测已连但车屏没有画面 | 确认官方 2023 Ford F-150、驾驶室视角、车辆通电和原厂 GPS 页面；等待地图准备完成 |
| 左 Alt 无法操作 | 确认游戏焦点、退出暂停菜单，再检查「控制」页绑定和长按 / 按一次模式 |
| 视频无声 | 确认播放未暂停，检查 Windows 输出设备、音量混合器中 WestPlay / WebView2 的音量和网络 |
| 时间差一小时 | 部分 `secondary timezone` 子区域尚未支持；详见时区验证文档 |

反馈问题时请附 ATS / WestPlay 版本、车辆、复现步骤及必要日志；公开前去除账户、个人存档路径和不必要的私人信息。

## 10. 已验证范围和项目来源

本分支实测基于 **ATS 1.61.3.18s / DX11 / Windows x64 / 2023 Ford F-150**，覆盖原车屏显示与操作、地图与游戏导航同步、短途道路驾驶、无需登录的 YouTube 播放和声音、主题切换、已有游戏连接及受控浏览器故障恢复。未完成长途全程、全部 DLC、全部 MOD、全部分辨率或长期压力验证。内部宿主 / 浏览器有有限次数自动恢复，整个 WestPlay 进程退出后需要自行重新打开。
