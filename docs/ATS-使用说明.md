# ATS WestPlay 使用说明

这是 WestPlay 的 American Truck Simulator（ATS）适配分支。原项目：<https://github.com/enes-less/WestPlay>。保留 GPL-3.0-or-later 许可证及第三方声明。

## 安装与首次设置

1. 使用本分支生成的 `ATS WestPlay_*_x64-setup.exe` 安装程序，可选择简体中文。安装界面提供快捷方式选项。
2. 打开「ATS WestPlay」，按首次设置向导确认本机 ATS 位置。游戏插件和屏幕资源的安装在程序内完成；若文件正在被游戏使用，请自行正常退出游戏后重试。
3. 完成设置和原版操作教程后，进入默认的「ATS 启动台」。

安装器内包含本分支的 `westplay.dll`、界面资源及许可证。Ford DLC 的拥有情况、激活状态和当前游戏版本的车内兼容性需要分别确认；检测到 DLC 文件并不代表已通过游戏内验收。

2026-10-27 已完成本机安装、去「支持我」版及最终 generation 修复版的就地升级验收：61 个安装文件哈希全部匹配，桌面和开始菜单快捷方式均指向安装版，参数为 `--launch-ats`。桌面入口已实测启动 ATS，并在保留游戏运行、升级宿主后重新连接同一个游戏，原车 WestPlay 画面恢复；未重复启动 ATS。安装结果不等于所有服务和使用环境已验证。

## 日常使用

2026-10-28 按用户要求改为手动启动游戏：桌面和开始菜单快捷方式均不附带 `--launch-ats`，新版安装器也保持此默认值。上一节的自动启动验收属于变更前的历史记录。

首次设置完成后，双击「ATS WestPlay」桌面或开始菜单快捷方式，只打开伴侣程序，随后自行通过 Steam 启动 ATS。也可以先开游戏、再开 WestPlay；两个程序运行后会自动连接。游戏未启动时显示「等待游戏」属于正常状态。请在使用中控期间保持 WestPlay 运行，首次地图准备完成后再使用导航。

手动启动不影响原车中控、地图和媒体功能。游戏和 WestPlay 都要运行，且游戏插件须已部署。若希望由 WestPlay 启动 ATS，仍可主动点击「ATS 启动台」的「启动 ATS 游戏」按钮；仅打开伴侣程序不会触发这个按钮。

在 ATS 中进入要使用的档案，选择官方 Road Trip: Ford DLC 的 2023 Ford F-150，并切换到车内第一人称视角。真实游戏已验证原厂中控显示、按住左 Alt 点击、地图缩放、搜索与导航同步，以及公共道路短途低速驾驶时 GPS 跟随；最终安装版重连后的车内显示也已验证。完整路线和其他车辆/游戏版本仍需分别验证。

「ATS 启动台」保留以下入口：

- **实时连接**：WestPlay 服务、游戏遥测、中控屏绘制状态。
- **检查连接**：重新读取本机安装、版本、插件、MOD 和 DLC 文件信息。
- **诊断与修复**：交给本分支后台处理部署问题；游戏运行期间拒绝修复，不代替用户强制关闭游戏。
- **查看日志**：打开本机日志目录，便于查找启动、插件或地图问题。
- **设置**：进入原版安装设置页；控制键、界面个性化和地图仍在原侧栏中。
- **音乐与视频账户**：进入原版账号页，按服务自身要求授权。
- **安全卸载**：使用原版卸载流程移除 WestPlay，并选择是否保留设置和地图。

地图、Spotify、Apple Music、YouTube Music、YouTube 和原版界面设置均沿用上游功能实现。需要账户或订阅的功能仍需正常登录和授权。

第一轮 YouTube 已实际完成未登录播放、暂停、返回列表和再次播放，并从 WebView2 音频服务录得非零媒体音轨。Apple Music 已打开真实未登录首页和目录；订阅播放、Spotify、YouTube Music、歌词和各服务切歌尚未完成端到端验证。详细范围与证据见 [本机实测记录](ATS-实测记录.md)。

本分支已按用户要求移除「支持我」页面、赞助入口及对应的本机打开命令。设置、账户、控制、地图和卸载等原有入口继续保留。

## 诊断和恢复

如果「游戏遥测」一直等待连接，先点击「检查连接」，展开「安装检查详情」核对游戏位置和插件状态。若游戏正在运行，请先自行退出，再执行修复并重新启动。

更新后若启动预检提示插件版本或部署资源不匹配，先在 ATS 退出状态下执行「诊断与修复」，然后重新启动。实测中旧 DLL 曾被预检拦截，安装版界面的修复已成功部署与新包匹配的 DLL；不应通过忽略预检继续启动。

如果遥测已连接而中控屏仍等待驾驶室画面，请核对是否使用目标车辆、是否在第一人称驾驶室中，并查看插件日志。此时不能仅凭遥测连接认定屏幕集成成功。

本分支取消了原项目自动更新地址。请使用本分支的安装包更新，避免安装回 ETS2 原版。

时区修复安装版已在 North Platte 同画面对照：WestPlay22:09与原厂HUD10:09PM一致；关闭时区后已验证实际ATS云档选项写盘及车屏显示。最终安装版还完成一次真实WebView2浏览器退出测试，自动恢复后共享纹理代号改变，插件重新打开纹理，原车WestPlay页面恢复，并实际点击切换Maps成功。运行中执行`g_set_time 6`、`g_set_time 12`及本机100%→原300%渲染缩放后，车屏保持正常。机制和范围见 [时区验证](ATS-时区验证.md)、[后台恢复验证](ATS-后台恢复验证.md) 与 [实测记录](ATS-实测记录.md)。secondary子时区矩形尚未支持；全部分辨率、完整跨日边界、长途驾驶和长期反复故障没有广泛验证。

## 开发构建

需要 Node.js、Rust MSVC 工具链和 Windows C++ 构建工具。仓库根目录执行：

```powershell
npm install
npm --prefix ui test
powershell -NoProfile -ExecutionPolicy Bypass -File tools/package-ats.ps1
```

脚本先编译原生插件，再调用 Tauri 构建 NSIS 安装程序，最后列出安装程序 SHA256。安装程序位于 `target/release/bundle/nsis`。构建成功属于工程检查，不能代替真实 ATS 测试。

当前功能状态见 [ATS 功能对照表](ATS-功能对照表.md)。
