已知工程边界：普通浏览器打开 companion 时，「ATS 启动台」明确标为界面预览并禁用本机操作。遥测连接、DLC 文件存在及插件版本匹配都不能独立证明 Ford 原车屏幕集成成功。

2026-10-27 的安装证据为 `installed-generation-fixed-artifacts.json`：`passed`、61文件、0失败。先前去支持版的桌面启动由日志13:29:21及host10408/game9720证明；该版升级后host29316连接同一个game9720，截图104显示WestPlay，截图106证明真实浏览器故障后恢复。当时安装器SHA256为`F54210893C170EDD2AE2202DE66F69AE14B6F8FBA863A32410F6B893260548BC`。这些PID仅用于对应本次证据，不是日常使用时的固定值。

2026-10-28 的手动启动版已重新打包、覆盖安装并校验61个文件；桌面和开始菜单参数均为空，实际打开桌面入口后 WestPlay 运行而 ATS 未启动。此版安装器SHA256为`0753314A417C72D241AEE6F5D3F1FD38EF067E7C689E2C91C8BC7E113EEB7691`，与公开首次发布的安装器一致。以后下载请以对应 Release 的 SHA256 清单为准。
